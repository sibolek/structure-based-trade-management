# Structure-Based Trade Management

A compact Vite + React + Tailwind execution dashboard for structure-based trade management.

This project is separate from setup and market concept notes. It governs trade permission and post-entry management.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Operating Premise

Structure decides. P&L emotion does not.

The setup earns attention. The stop decides whether the trade is allowed. The target decides whether the risk is worth it. The plan decides whether the trade can be held.
