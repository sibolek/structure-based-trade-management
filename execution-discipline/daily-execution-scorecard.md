# Daily Execution Scorecard

> A green day can be a C execution day. A red day can be an A execution day.

Purpose:

Grade execution separately from P&L.

| Category              | A-Grade Requirement                    | Grade | Notes |
| --------------------- | -------------------------------------- | ----- | ----- |
| Instrument discipline | MES only                               |       |       |
| Trade count           | 1–4 trades                             |       |       |
| Loss limit discipline | 0–2 losing trades                      |       |       |
| Setup clarity         | Setup named before entry               |       |       |
| Level discipline      | Trade taken at predefined zone         |       |       |
| Trigger discipline    | Trigger occurred after setup was valid |       |       |
| Stop discipline       | Stop placed at structural invalidation |       |       |
| Target discipline     | Target defined before entry            |       |       |
| No recovery trading   | No trade taken to get money back       |       |       |
| Emotional control     | No revenge, rescue, or urgency trades  |       |       |
| Journal quality       | Every trade tagged and reviewed        |       |       |

## Daily Review Questions

1. Did I trade only MES?
2. Did I take 4 or fewer trades?
3. Did I take 2 or fewer losing trades?
4. Did I name the setup before every entry?
5. Did every trade occur at a meaningful level?
6. Was every stop based on structural invalidation?
7. Did I take any trade to recover a loss?
8. Did I stop when my rules said to stop?
9. Was today’s execution grade better than my P&L grade?
10. What is tomorrow’s one execution improvement?
