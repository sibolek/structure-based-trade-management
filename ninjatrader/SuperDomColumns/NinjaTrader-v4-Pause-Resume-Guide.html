Install and enable the test

The new setting defaults to False. Set it True explicitly after installing. Otherwise this build continues strict quote suppression.

  1. Save current v4 settings and back up the installed source outside NinjaTrader 8/bin/Custom.
  2. Replace the entire existing ExecutionOSPullingStacking_v4_Experimental script with the full source linked above. Save and compile with F5. Use one v4 column; do not create a duplicate class or add an earlier version. The ZIP is a source/review bundle, not an import archive.
  3. Verify the column’s Build says 2026-10-16.5 EXP. Reload that column only if it remains on the older build, then restore its settings.
  4. Set Flow detection (experimental) → Pause qualified events on quote loss = True. Changing this option rebuilds detection, clears the last-event record and requires fresh warm-up.
  5. Apply the settings below and leave your current detection thresholds unchanged.
  6. Open NinjaScript Output, collect about five minutes after warm-up, and send the complete Quote/Flow/P/S text with its instrument and NT-local time span. A video is unnecessary for this first lifecycle check.

The original clock keeps running

With a 3000 ms Marker display lifetime:

This is a synthetic lifecycle example, not historical DOM evidence. There is no new grace timer and no extra three seconds after recovery. The support recheck uses current, unexpired retained evidence and existing quiet/age rules; an old qualification cannot bypass them.
